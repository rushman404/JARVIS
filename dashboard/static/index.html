    GEEN VERBINDING MET JARVIS
    Deze iPad kan de laptop niet bereiken. Controleer:
    1. Draait JARVIS op de laptop, met DASHBOARD_ENABLED=1?
    2. Is het certificaat volledig vertrouwd? Instellingen → Algemeen → Info → Instellingen voor certificaatvertrouwen → zet JARVIS Dashboard CA aan. De app op het beginscherm heeft dit nodig; Safari kan het soms zonder.
    3. Hoort het certificaat bij het huidige IP-adres van de laptop? Bij het starten meldt JARVIS het in de console als dat niet zo is.
    4. Zitten de iPad en de laptop op hetzelfde wifi-netwerk?
